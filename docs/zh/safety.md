# 安全与限制

## 默认安全行为

- 默认 **预览**：只打印会动到谁，不结束进程。  
- `GameMode-Apply.bat` 会要求你输入 `Y` 才继续。  
- 永不杀列表硬编码，用户排除无法「反过来」强制杀掉它们。  
- 优先结束**当前用户**可见进程；不要求管理员也可做大部分清理。  

## 明确不做

- 不删文件、不格式化磁盘、不勒索  
- 不永久关闭 Windows Defender / 安全中心  
- 不写恶意注册表、不植入启动项  
- 不用未公开内核手法刷 Standby List（本版只做进程安静）  
- 不含交易、券商、MiniQMT 代码  

## 诚实预期

- 能减少后台内存/CPU 争用，方便低配机器开游戏。  
- **不保证**帧数、不保证任何 3A 大作流畅。  
- 「可释放内存」是匹配进程工作集的粗算，系统实际回收可能更少或更多。  

## 权限

若个别进程提示权限不足：那是正常的（系统/其他用户会话）。跳过即可，不要为了强杀去关杀毒。
